## @httpx/barcode

Benchmarks to measure [@httpx/barcode](../README.md) performance.

### Run

```bash
pnpm install
cd packages/barcode
pnpm build
pnpm bench
```

Published results were measured with Node 26 (ie: `nvm use 26`).

### Notes

- The benchmarks run on the built files (`dist`), see [get-barcode.ts](./get-barcode.ts).
- [compare-zod.bench.ts](./compare-zod.bench.ts) compares `isGtin` with an equivalent zod schema, regular and compiled (`z.compile()`, strict mode to ensure it's actually compiled). Implementations are checked to agree on every code before being measured.
- [parse-gtin.bench.ts](./parse-gtin.bench.ts) compares `parseGtin` (default, `trim: false`, with `types` / `inputTypes`) and `parseGtinOrThrow` (try/catch) with `normalizeGtin`, on mixed strings, valid strings and numbers (leading zeros lost). `parseGtin` is checked to agree with `normalizeGtin` on every value before being measured.
- [detect-barcode-type.bench.ts](./detect-barcode-type.bench.ts) measures `detectBarcodeType` with and without trimming (`trim: false`), trimming has a fast path when both ends are digits.
- Codes are generated by [bench-seeds.ts](./bench-seeds.ts): 1000 deterministic codes, mostly ean13, ~20% invalid.
